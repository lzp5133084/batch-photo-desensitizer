CORE ENGINE

四层隐私清理，全部本地完成

不依赖云端服务，不产生任何上传记录；处理结果另存新文件，原图永远保持原样。

01 / METADATA

元数据彻底清除

删掉 EXIF 里的 GPS 经纬度、相机型号、拍摄时间、修图软件、内置缩略图。别人拿到照片，再也查不到你在哪、什么时候、用什么设备拍的。

GPS 定位设备型号时间水印XMP
02 / FACE

人脸自动打码

本地 OpenCV 多模型融合识别人脸，支持马赛克、高斯模糊、纯色遮盖三种方式，三档灵敏度可调，远景小脸也能处理。

正脸侧脸多人合影
03 / PLATE

车牌自动遮挡

先用蓝、黄、新能源绿三种车牌底色锁定候选区域，再用文字识别引擎做二次确认，误检压到最低。只遮车牌，不碰车身与背景。

蓝牌黄牌绿牌OCR 复核
04 / TEXT

文字敏感信息打码

本地 OCR 识别画面文字，自动定位身份证号、手机号、银行卡号与证件文字行；也可以一键遮住全部文字。名片、合同、快递单同样适用。

身份证号手机号银行卡号全文字
05 / BATCH

批量队列与操作记忆

拖进整个文件夹即可成批处理，进度、成功失败、每张检出明细逐条记录。参数自动记住，历史记录一键复用上次的设置。

拖拽导入批量队列参数记忆历史复用
06 / API

命令行与接口可复用

内置 CLI 与本地 HTTP 接口，其他程序可以直接调用做自动化：脚本批处理、业务系统嵌入、定时任务都能对接。

CLIHTTP API可嵌入
WORKFLOW

四步走完，原图一张不动

处理结果统一另存到输出目录，原文件只读不写，随时可以反悔。

1

导入照片

点「添加照片」或直接把图片、整个文件夹拖进左侧队列，支持 JPG / PNG / WEBP / BMP / TIFF。

2

试算一次

点「试算」，先在当前选中照片上预览检出结果（人脸几处、车牌几处、文字几处），确认无误再批量。

3

选择要清理的项目

元数据、人脸、车牌、文字四类自由勾选，每类可调打码方式与强度；也可以在预览图上手动补框。

4

开始去敏

一键批量处理，完成后自动打开输出目录；日志里能看到每张照片的耗时与检出明细。

启动桌面版

网页演示只能做「手动框选打码 + 清除元数据」。人脸、车牌、证件号与手机号的自动识别，需要桌面版引擎（OpenCV + 本地 OCR）。

  1. 双击桌面「程序 / 批量相片去敏工具」文件夹里的快捷方式；
  2. 或运行程序目录下的「启动_批量相片去敏工具.bat」；
  3. 把照片或整个文件夹拖进左侧队列，勾选要清理的项目，点「开始去敏」。

桌面版不需要账号、不联网，处理好后自动打开输出目录。
